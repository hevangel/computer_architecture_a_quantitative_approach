Start here

Install Python 3, Icarus Verilog 12 and GHDL 4.x, then run these commands from this textbook repository. The browser links below open guides and source files; simulations run locally.

make list                    # discover the examples
make test                    # run both HDL test suites
make test T=set_assoc_cache   # run one example
make test-sv                 # SystemVerilog only
make test-vhdl               # VHDL only
